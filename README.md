# 📱 Proyectos React Native

Este repositorio contiene una colección de proyectos desarrollados en React Native como parte de mi aprendizaje y práctica en desarrollo móvil.

## 🚀 Proyectos incluidos

### 📌 01 - Bases
Proyecto introductorio con conceptos básicos de React Native.

### 📌 02 - Testing App
Aplicación enfocada en pruebas y validación de funcionalidades.

### 📌 04 - Calculator App
Aplicación de calculadora con lógica de operaciones matemáticas.

### 📌 05 - Navigation App
Implementación de navegación entre pantallas utilizando React Navigation.

## 🛠️ Tecnologías utilizadas

- React Native
- JavaScript / TypeScript
- React Navigation
- Expo
